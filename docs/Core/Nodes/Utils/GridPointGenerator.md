# GridPointGenerator Node

<img class="node" src="https://github.com/Voronoi-Studios/GridWave/raw/main/docs/Images/Nodes/GridPointGenerator.png" alt="GridPointGenerator"/> 

Allows for easier generation of Positions in a grid, based on a grid size and repeat count. 

Is equivalent to using a SquareGrid with a Scaler and a Bounds node.
If **directly** plugged in to an Algo node, the bounds and grid inputs on that Algo node can be left empty as this node provides them.
