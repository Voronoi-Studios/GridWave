# StaticMirrorProp Node

<img class="node" src="https://github.com/Voronoi-Studios/GridWave/raw/main/docs/Images/Nodes/StaticMirrorProp.png" alt="StaticMirrorProp"/> 

Allows to flip prefabs across the specified axis. This node exists as behind the scenes this is used to reduce variants of tiles.
