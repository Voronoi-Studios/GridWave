# GridBoundsGenerator Node

<img class="node" src="https://github.com/Voronoi-Studios/GridWave/raw/main/docs/Images/Nodes/GridBoundsGenerator.png" alt="GridBoundsGenerator"/> 

Allows for easier generation of bounds based on a position, grid size (offset) and the amount of times this grid offset is repeated.

---

* Green dot -> Position
* Distance between points -> Offset
* Number of points in each direction -> Repeat

Left image -> Not Centered / Right image -> Centered
