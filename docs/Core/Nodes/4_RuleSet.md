# RuleSet Nodes

Defines each edge of a cell
Can be read from in the folder `Server/HytaleGenerator/RuleSets` 

## Variants

---

### Simple RuleSet (Horizontal Rules)

<img class="node" src="https://github.com/Voronoi-Studios/GridWave/raw/main/docs/Images/Nodes/SimpleRuleSet.png" alt="SimpleRuleSet" />

Use some sort of key to define what the corresponding edge can connect to.
Multiple keys can be entered by using `,` as a separator

### Advanced RuleSet (Horizontal Rules)
<img class="node" src="https://github.com/Voronoi-Studios/GridWave/raw/main/docs/Images/Nodes/AdvancedRuleSet.png" alt="AdvancedRuleSet" />

Use some sort of key to define what the corresponding edge can connect to.
The advanced variant allows you to specify separately "Who am I" => Provider RuleSets and "Who do I like" => Reciever RuleSets.

Multiple keys can be entered by using `,` as a separator
